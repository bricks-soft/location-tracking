# @bricks-soft/capacitor-location-tracking

Background location tracking for Capacitor 8: continuous and motion-aware tracking with Google Play services (GMS),
Huawei Location Kit (HMS) or the plain Android `LocationManager`; geofencing; SQLite persistence with HTTP sync; and
audit records (`heartbeat`, `tracking_start`, `tracking_stop`, `providerchange`) that let a server detect gaps in
tracking. Android is supported now; iOS is planned for a later phase.

Documentation in progress; see [docs/architecture.md](docs/architecture.md).
